# AutoSA, as the external baseline

Generated by [AutoSA](https://github.com/UCLA-VAST/AutoSA) (Wang et al., FPGA'21),
MIT licensed, and checked in so the comparison in `SPMW_EXPERIMENTS.md` §5 can be
read rather than taken on trust. Nothing here is written by hand or by SPMW —
`input_kernel.c` is what we gave AutoSA, everything else is what it emitted.

| file | what it is |
|---|---|
| `input_kernel.c` | our GEMM with `#pragma scop` — the input |
| `kernel.h` | AutoSA's type/size header |
| `kernel_kernel.cpp` | **the generated array**, ~380 KB |
| `kernel_kernel.h` | its declarations |
| `kernel_host.cpp` | AutoSA's testbench |

## How it was generated

```
--sa-sizes="{kernel[]->space_time[3];kernel[]->array_part[16,16,16];
             kernel[]->latency[1,1];kernel[]->simd[1]}"
```

`latency[1,1]` gives each PE a 1×1 tile of C, so 256 PEs. `simd[1]` keeps the PE
scalar — AutoSA's SIMD packs N lanes at any width rather than auto-packing narrow
types, so this is the setting that matches SPMW.

`space_time[3]` is **output-stationary**, confirmed by reading the generated PE
rather than trusting the flag: one `local_C[1][1]` accumulator held across the
whole `k` loop, written out at the last iteration, and no `fifo_C_in`.
`space_time[4]` and `[5]` are output-flowing — the partial sum arrives on a
stream — and would have made the comparison meaningless.

## What to compare, and what not to

`grep -c '^void' kernel_kernel.cpp` counts what AutoSA emits as one monolithic
kernel: ~595 module instances. Only two groups have an SPMW counterpart — the
256 PEs and the inter-PE A/B FIFOs. The rest is a C-drain network, a 3-level
DRAM I/O network, and AXI master + AXI-Lite control, **none of which SPMW
generates at all**.

So the whole-kernel area comparison overstates AutoSA's cost by ~5×. Compare the
PE array only, and read §5's caveats before quoting any number from here.

Two build notes, in case this needs redoing: `src/autogen.sh` must be run twice
(the first pass emits no top-level `configure` and exits 0), and
`src/autosa_common.cpp:1231` compares an `isl_multi_pw_aff *` against `0`, which
GCC 11 rejects — upstream ppcg has `if (!index)`.
